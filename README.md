# 衡評述值 Pricetory

AI 時代，大部分工作都被 AI 取代。體驗者來到 AI 經營的企業應徵，兩間 AI 企業的高層用月薪競標他。

- **A｜顧承淵**（營運長 COO）：節點 1，Boy 模型
- **B｜程以墨**（創新長 CIO）：節點 2，middle 模型

## Demo 網址

`six-branch` 沒有放在 GitHub Pages 上，可以用 githack 直接開（第一次會出現提醒頁，按「Open the page」）：

- 電腦一（主控，A 顧承淵）：`https://raw.githack.com/zoeytan-design/infection-echo/six-branch/index.html?host=1`
- 電腦二（B 程以墨）：`https://raw.githack.com/zoeytan-design/infection-echo/six-branch/index.html?host=0`

網址最後的 `?host=1`／`?host=0` 指定這台是不是主控電腦，不用再勾選。請用 Chrome 開，並允許鏡頭和麥克風。

## 開場前準備

1. 兩台電腦都用 Chrome 開啟網頁。
2. 電腦一選 **A 顧承淵**，並勾選「這台是主控電腦」。鏡頭、麥克風、鍵盤都接這台。
3. 電腦二選 **B 程以墨**，不要勾主控。
4. 兩台電腦各自從自己的喇叭念出自己角色的台詞。

只開一台電腦也能測試：另一個角色不在線時，主控電腦會代念他的台詞。

角色人設存在 Firebase。如果 Firebase 裡還是舊版資料，程式會自動改用內建的預設人設。要修改人設，請到「系統設定」編輯後按「發布」。

## 主控電腦的鍵盤

| 按鍵 | 作用 |
|---|---|
| 1～5 | 放上職業卡（1 平面設計師、2 動畫師、3 網頁設計師、4 品牌策略與定位設計、5 遊戲設計師） |
| 0 | 拿起職業卡：面試立刻中止 |
| Enter | 不等鏡頭直接開始／提早結束 15 秒自我介紹 |
| A／B | 敲槌，與該企業成交 |
| T | 打字代替說話（麥克風有問題時的備案） |
| R | 重置 |

## 流程

1. 放卡後，體驗者面對鏡頭（或按 Enter）開始，3 分鐘倒數。
2. **自我介紹 15 秒：** 體驗者說明為什麼想應徵這個職位。
3. **第一輪：** 兩位 AI 都會發言，決定出價的人先講，而且先報價再說原因。這一輪體驗者說的話不會被處理。
4. **開放階段：** 麥克風一直開著，體驗者可以隨時補充，或開出期待的月薪（反向出價）。AI 對反向出價會接受、還價或拒絕，但都要等敲槌才算成交。體驗者沒說話時，兩位 AI 會互相對談。
5. **互相爆料：** 兩位 AI 都出價至少 2 次後觸發，一場一次，由隨機一方先爆料、另一方反擊。
6. **敲槌（A／B）：** 第一輪結束後才有效。選到的一方如果還沒出價，敲槌無效，他會回一句警語；有出價就以他目前的出價成交。
7. 3 分鐘到了就結束，未成交。

## 可調整的設定

都在 `index.html` 的主程式開頭：

- `TOTAL_MS`：整場面試時間
- `INTRO_MS`：自我介紹時間
- `LISTEN_WINDOW_MS`：每位 AI 講完後等體驗者插話的時間
- `EXPOSE_AFTER_BIDS`：觸發爆料的出價次數
- `SALARY_CAP_RATIO`：出價上限倍數
- `CARDS`：職缺、月薪範圍、RFID 卡號

## 硬體（之後再接）

- 已寫好的 RFID 程式（`pricetory_rfid.ino`，送出 `TAG:`、`TAG_OFF:`）和敲槌程式（`pricetory_button.ino`，送出 `HIT`）可直接接上。在主控電腦的「系統設定」按「連接 Arduino」，各選一次連接埠即可。
- 收到 `HIT` 時目前只會提示「請按 A 或 B」，因為還沒決定敲槌時怎麼選成交對象。
